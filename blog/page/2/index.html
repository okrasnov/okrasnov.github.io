2023-12-13

Forward Model of Radar Signals in the Distributed Radar System

Finally, decided to published on the GitHub my radar network simulator, which where developed back to 2012…

RadarNet-FWM: Forward Model of Radar Signals in the Distributed Radar System

It is a simple MATLAB simulator of the set of non-directive radars that are working simultaneously but independently and observes the same set of targets. The simulator generates a timeline of coherently processed bursts of sensing waveforms with specified parameters, which are presented as a set of received signals on the range-Doppler plane.
